Nothing is mocked

The numbers above are counted from the vendored engine at page load, not typed into this page. Team validation runs through Showdown's own TeamValidator, and battles run through its BattleStream — the same code path a real ladder game takes.

That means when the builder tells you Great Tusk can't learn Hydro Pump, it is the cartridge's learnset saying so.
